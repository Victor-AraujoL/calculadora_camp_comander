# Calculadora de Campeonato Commander

Calculadora web para organizar mesas, cronometro, resultados e classificacao de um campeonato Commander.

## Usar localmente

Abra `index.html` no navegador. Como o projeto e estatico, nao precisa instalar dependencias.

## Publicar no GitHub Pages

No terminal, dentro desta pasta:

```bash
git add index.html README.md
git commit -m "Publica calculadora de campeonato"
git push origin main
```

Depois, no GitHub, abra **Settings > Pages**, selecione **Deploy from a branch**, escolha a branch `main` e a pasta `/ (root)`, e clique em **Save**.

O endereco sera:

`https://victor-araujol.github.io/calculadora_camp_comander/`

Pode levar alguns minutos para ficar disponivel. O arquivo `index.html` e o ponto de entrada exigido pelo GitHub Pages.
